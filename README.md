# ЛР №2. Опрацювання масивів із застосуванням циклів

**Предметна область:** електронний облік пацієнтів.

## Сутність `Patient`

| Поле         | Тип      | Опис                    |
|--------------|----------|-------------------------|
| `cardNumber` | `String` | номер медичної картки   |
| `fullName`   | `String` | ПІБ пацієнта            |
| `birthYear`  | `int`    | рік народження          |
| `weight`     | `double` | вага, кг                |
| `diagnosis`  | `String` | поточний діагноз        |

Клас має конструктор, гетери, перевизначені `toString()`, `equals()` і `hashCode()`.

## Що реалізовано

- **Рівень 1.** Введення масиву пацієнтів з клавіатури (`Scanner`) у циклі `for`, виведення через `for-each`, підрахунок пацієнтів, старших за заданий вік.
- **Рівень 2.** Сортування методом простого вибору (selection sort) за роком народження, без `Arrays.sort()` / `Comparable`. Масив виводиться до і після сортування.
- **Рівень 3.** Лінійний пошук за цілим об'єктом-зразком через власний `equals()`.
  Порівняння — за номером картки, ПІБ і роком народження: ці поля ідентифікують людину, а вага й діагноз змінюються між візитами.

## Запуск

Потрібен JDK 17 або новіший.

```bash
javac -encoding UTF-8 Patient.java Main.java
java Main
```

На Windows перед запуском у консолі виконайте `chcp 65001`, щоб коректно відображалася кирилиця.
